# HALF-IMS

The source code, installation instructions, and manual for the usage of the current iteration of the HALF-IMS software.

# Note
To make use of the software referenced in DOI: [10.1021/acs.analchem.8b05577](https://pubs.acs.org/doi/suppl/10.1021/acs.analchem.8b05577/suppl_file/ac8b05577_si_001.pdf), please checkout the v1.0 tagged commit of this repository. This commit contains the LabView and MATLAB scripts mentioned along with usage instructions. Publications (i.e. articles, book chapters, etc.) that use this software are required to cite the related article (https://pubs.acs.org/doi/full/10.1021/acs.analchem.8b05577).
